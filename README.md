# 巅峰人生 V2 · 原生微信云开发

这是一个独立项目，在微信开发者工具中导入**当前目录**，不要导入上一级旧项目。沿用原项目已有 AppID `wx892f2174d0293f28`，可在 `project.config.json` 换成你自己的小程序 AppID。前端无第三方运行依赖，无 WorkBuddy SDK。

## 已实现

- 26道单选题：2道背景、19道计分、5道解释；按实际作答计算六方面指数与综合指数。
- 点选后180毫秒自动下一题，支持上一题；连续点击和后台过期回调不会误答下一题。
- 7天本机草稿，最后一题自动提交，失败保留答案；重试幂等，改答后使用新的提交编号。
- 八种有证据的自嘲类型、组合解析、六方面详情和一件可记录的小行动。
- 微信云函数自动识别OPENID；无登录页、个人中心、资料授权或手机号/昵称/头像采集。
- 私有历史报告、删除、7天过期公开分享、主动撤销；公开字段为白名单摘要。
- 原生微信好友分享和Canvas海报；使用`wx.previewImage`让用户长按保存，不调用相册授权。

## 连接微信云开发

1. 在微信开发者工具导入当前目录；使用有权限访问该AppID云开发环境的开发者账号。
2. 在云开发面板选择要用于本项目的环境，复制**环境ID**。无需为终端用户增加登录或授权界面。
3. 在 `miniprogram/config.js` 的 `cloudEnv` 填写环境ID。不要填“cloud1”等显示名称，除非它本身就是实际环境ID。
4. 在该环境创建三个集合：`peak_life_results`、`peak_life_requests`、`peak_life_shares`。
5. 三个集合的客户端安全规则均设置为 `{"read":false,"write":false}`。`database-rules.json`是逐集合规则清单，需分别粘贴各自内容，不是一次上传的云部署配置。所有读写通过云函数进行，不能开启客户端直接读写。
6. 为 `peak_life_results` 建立组合索引：`owner`升序、`createdAt`降序、`_id`升序，用于本人历史记录排序。
7. 首次先在项目根目录运行 `npm ci`，再运行 `npm run build:cloud`。云函数 `main.js` 和 `lib/` 是源码，`index.js` 是生成的单文件部署入口，包含全部本地业务模块及题库，避免Windows打包路径在Linux运行时失效。修改后端或生成题库后必须重新构建。然后右键 `cloudfunctions/peakLifeApi`，选择“上传并部署：云端安装依赖”。函数名必须为 `peakLifeApi`，选择支持Node.js18或更新版本的运行环境；建议超时20秒、内存256MB。函数使用已固定版本的 `wx-server-sdk`，`cloud.DYNAMIC_CURRENT_ENV`绑定当前部署环境。
8. 重新编译，点击“测出我的生活配置”，完成26题验证真实提交、历史读取与分享。

已按用户提供的环境ID配置为 `cloud1-3gbiogrx67d1e65c`。2026-10-15已部署云函数版本 `2026-10-15.5`，通过开发者工具调用实际云端，验证正式提交、报告读取、同编号重试和历史列表。业务模块已打包进入单个 `index.js`；入口剥离微信注入的 `userInfo` 和 `tcbContext`，用户身份仍仅取可信SDK上下文。若移植到其他小程序，请同时修改AppID和环境ID。云环境未配置时首页明确提示，无法提交时显示错误并保留答案。所有报告和公开分享均由云函数读取或创建。

## 数据与计分

正式计分与类型条件均在 `cloudfunctions/peakLifeApi/lib/`，客户端只提交选项ID。综合指数六方面等权，年龄和身份不加分；缺项不当作零分，有效计分项不足时不输出综合指数。

项目没有经过校准的真实同龄样本，因此不提供同龄排名。没有固定成绩、合成人物或假设概率表。新报告、历史报告列表、旧报告读取和旧分享链接均只展示实际作答指数，旧的模拟百分位不再通过接口返回。详细规则见 [docs/MODEL.md](docs/MODEL.md)。

修改本项目内的题干源文件 `docs/QUESTION_BANK.md` 后运行 `npm run generate`，同时生成微信可加载的 `miniprogram/data/questions.js` 和服务端JSON。客户端不能直接 `require` JSON文件。生成器默认保留“不好判断／先不答”，包括背景题；跳过年龄不给同龄排名。本目录可独立移动，不依赖上一级旧项目。

## 隐私与存储

- 不调用`wx.login`、`wx.getUserProfile`、`wx.authorize`，不申请位置、头像、通讯录或相册权限。
- 用户选项在本机7天内可恢复，过期后下次读取时删除，成功提交后清除；“数据与隐私”页面可手动清除草稿。
- 云端以服务端OPENID校验归属，客户端不能提交owner或成绩。完整答案仅用于生成报告，不单独落库；云端仅保留报告、展示所需的答案依据和解析、提交指纹及必要分享元数据。报告仍可能含用户选择的收入/存款等档位，仅本人可见。
- 本人读取旧报告、历史列表或重试提交时，事务清理旧的完整答案和停用贡献字段；清理保留报告、完成状态、分享撤销版本及幂等指纹，不跨用户操作。
- 分享token由服务端安全随机生成，只保存SHA-256摘要，7天过期；撤销以结果版本号使全部旧链接失效，删除报告也立即使其分享不可读取。
- 删除会移除本人报告。幂等请求指纹作为防重复墓碑保留。新分享记录仅保存报告编号、撤销版本和过期时间，公开摘要在读取时生成；旧分享摘要在有效读取时清理，尚未读取的旧版本过期/撤销摘要仍需运营清理。删除不承诺远程删除他人已经保存的图片。
- 作答用于生成本人报告，不采集人群校准贡献开关。旧客户端的`contribute:false`仅作为兼容字段接受。

## 本地验证

需要Node.js18以上，建议Node.js22。前端不需要构建npm。

```sh
npm ci
npm run generate
npm run build:cloud
node scripts/generate-icons.js
npm test
npm run check
```

自动化验证位于 `tests/`，仅在本地运行，不进入小程序或云函数运行包，也不写入微信云数据库。验证覆盖计分、缺项、归属、提交重试、分享生命周期、行动不改分、自动跳题、旧排名停用与图片脱敏。`check`校验路由、事件、JSON/JS语法、题库一致性及无登录/授权API；本机安装微信开发者工具时还调用原生WXML/WXSS编译器。

本地单元测试与模拟器界面验证不等于真实云部署通过；云端集合、权限、索引和函数部署后，还需用两个微信身份验证归属和分享，再做真机窄屏/大字体检查。仓库不包含可确认归属的云端测试记录清单，本次代码清理不会批量删除云端用户报告。
